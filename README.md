# ろくろ日和 — 指先で陶芸ゲーム

**スマホ・PC対応の、無料・依存ライブラリなしのブラウザゲーム**です。粘土を左右にドラッグして陶器の形をつくり、5つのお題への一致度を競います。

## 遊びかた

1. 「ろくろを回してみる」を押します。
2. 器の左右どちらかに指（マウス）を置いて、**外側に引くとふくらみ**、**内側に押すと細く**なります。
3. 加工したい高さでドラッグし、お題の点線に近づけてください。
4. 5色から釉薬を選び、「この器を完成させる」で採点します。
5. 作品棚には**各お題の最高得点作品**が自動保存されます（ブラウザのローカルストレージ）。

操作補助：ひとつ戻す、最初から、点線ガイド表示の切り替え。キーボードでも、キャンバス選択後に ↑↓ で加工位置、←→ で細く／太くできます。Shift+←→ で大きく変更します。制限時間なし、効果音は初期設定でOFFです。

## GitHub Pages で公開する

**ビルド作業やサーバーは不要。** このフォルダの中身をリポジトリ直下にアップロードしてください。

```text
repo-root/
├─ index.html
├─ style.css
├─ game.js
├─ favicon.svg
└─ README.md
```

1. GitHubで新規Publicリポジトリを作成（例：`rokuro-biyori`）。
2. ZIPを展開し、**上記5ファイルをリポジトリ直下**にアップロード・コミットします。ZIPファイル自体をアップロードしないでください。
3. `Settings` → `Pages` → `Build and deployment` → `Source: Deploy from a branch` を選択。
4. `Branch: main` / `Folder: / (root)` → `Save`。
5. 公開されるURLは通常 `https://<ユーザー名>.github.io/rokuro-biyori/` です。公開まで時間がかかる場合があります。

既存のGitHub Pagesサイトのサブフォルダに置く場合も、相対パス指定なので動作します。

## 実装メモ

- HTML/CSS/JavaScript（Canvas 2D）だけで動作
- 外部ライブラリ・CDN・API・画像ファイルのダウンロード不要
- タッチ操作／マウス操作／キーボードに対応
- 作品の保存はブラウザ内だけで実施（サーバー送信なし）
- ソースコードを編集しての再配布・改変も自由です

開発者向けローカル確認： `python -m http.server 8000` でこのフォルダを公開し、 `http://localhost:8000` を開きます。ファイル直開きでも基本操作は可能です。
